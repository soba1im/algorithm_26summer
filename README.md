# 📝 Commit Convention

| Type | Description |
|------|-------------|
| `feat` | 문제 풀이 추가 |
| `refactor` | 코드 개선 및 리팩토링 |
| `docs` | README 및 문서 수정 |
| `fix` | 버그 및 오류 수정 |

### Example

```text
feat: 전화번호 목록 풀이
feat: 프린터 풀이
refactor: 큐 구현 개선
docs: Week01 README 수정
```

---

# 🌿 Branch Convention

| Branch | Description |
|--------|-------------|
| `main` | 최종 코드 |
| `week01/임소현` | Week01 작업 브랜치 |
| `week01/장현석` | Week01 작업 브랜치 |
| `week02/임소현` | Week02 작업 브랜치 |
| `week02/장현석` | Week02 작업 브랜치 |

해당 주차 종료 후, 그 브랜치는 삭제한다(main 브랜치에 PR & merge 후).

### Example

```text
week01/임소현
week01/장현석
week02/임소현
week02/장현석
```
